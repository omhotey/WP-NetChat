# Проверка выпуска 1.2.3

Один установочный ZIP — netchat-wp-1.2.3.zip: корень netchat/, 61 runtime-файл. SHA256: `ea60af44187b7d6cd499c007fa364776f054526cff7639d600e4981b24d8fbd3`. Пофайловые SHA зафиксированы в tools/build-release-1.2.3.py, manifest и SHA256SUMS создаются рядом с ZIP. Публичные пресеты — только основная нейтральная форма и пример; пользовательских данных, .git, тестов и стендов в пакете нет.

## Локальные проверки

Штатный `python tools/build-release.py` должен воспроизвести эти байты из текущего корня checkout. `--verify-only` сверяет готовый результат. Неизвестная/несогласованная версия, отсутствие builder/модуля CSS/require, изменение содержимого или состава runtime вызывают ошибку. Старый builder 1.2.2 сохранён отдельно, автоматического отката к нему нет.

`python tools/test-style-delivery.py --php php` выполняет изолированные PHP guards и синтаксис runtime без WordPress/БД/почты. Все CSS, JS, обработчики форм и почтовый модуль совпадают с 1.2.2; различаются версия, подключение модуля, его код и readme.

[Workflow GitHub Actions](https://github.com/omhotey/WP-NetChat/actions/workflows/ci.yml) собирает точный ZIP на Windows и передаёт его двум парам WordPress 5.0 / PHP 7.2 и WordPress 7.1.3 / PHP 8.3. Сохранены проверки SQL, форм, переноса, приватности, обновления с исторических 1.0.0/1.2.0, браузерных сценариев и почтового шаблона; отдельный шаг проверяет CSS guards. Перед выпуском проверьте успешность всех jobs для точного коммита или тега и SHA пакета на [странице релизов](https://github.com/omhotey/WP-NetChat/releases). Само наличие workflow не означает успешный результат запуска.

## Проверка после установки

Очистить кеш страниц/CDN; проверить обычный и внешний режим CSS, строгий CSP при его использовании, отсутствие дублированных стилей, холодный и повторный переходы. Проверить кнопку, подсказку, контакты, формы, шаги, modal/drawer и сохранность настроек/заявок. Реальные устройства, тема, автоматический cron и доставка писем требуют отдельной проверки сайта. Локальный PASS не равен production-проверке или приёмке владельцем.

Результат установки и проверку конкретного рабочего сайта фиксируйте отдельно от сборки и CI. [Загрузка CSS](CSS-016.md) · [Обновление и откат](UPGRADE.md) · [Тесты](../tests/README.md).
