# Перенос настроек и форм

Настройки включают независимые `button_scroll_percent` и `hint_scroll_percent`: целые числа 0–100 (поддерживаются также строки из цифр, нормализуемые в целые числа). В старом JSON отсутствующие ключи получают 0; остальные значения сохраняются. `null`, boolean, дроби, отрицательные числа, значения выше 100 и нечисловые значения отклоняются. Экспорт старого сохранённого конфига включает эффективные значения без записи в БД. Импорт только форм не меняет настройки. Preview и транзакционный CAS сравнивают исходные байты и revisions options до явного сохранения. Лишние и обязательные ветви со значением `null` также отклоняются.

Откройте NetChat → Перенос данных. Экспортируйте настройки, выбранные формы или общий комплект. В каталоге у каждой формы есть действие «Экспорт формы». JSON может содержать ваши контактные адреса, получателей уведомлений и тексты форм: храните его приватно. Заявки, снимки отправленных ответов, авторизация, сессии, salt, токены, ревизии, удалённая история и привязки страниц в файл не входят.

Для импорта выберите JSON до 1 МиБ. Файл сначала проверяется без записи. Выберите формы и при необходимости отметьте перенос настроек, документов или основной формы. По умолчанию существующие формы сохраняются, конфликты создают копию с новым ID и service_code. Для замены выберите конкретную существующую форму отдельно. Замена сохраняет её ID/code, повышает локальную schema_version и не меняет сохранённые заявки. Проверьте preview, затем отдельно нажмите «Применить проверенные изменения».

Настройки плагина заменяются полным выбранным комплектом, поэтому этот пункт исходно выключен. Документы/приём форм и выбор основной формы тоже требуют отдельной отметки. У новых/скопированных форм нет привязки к страницам: назначьте её на новом сайте. При явной замене сохраняется текущая локальная привязка. Импорт не сопоставляет сайты или реальные page_id автоматически. Основная форма остаётся единственной.

При конфликте 409 изменения не применяются: повторите preview после обновления страницы. Неизвестная схема, ключи, типы полей, небезопасные ссылки, неверные условия/ID, повторные ключи JSON и повреждённые файлы отклоняются. Права manage_options и действующий nonce обязательны. Оба options сохраняются в одной проверенной InnoDB-транзакции с блокировкой и CAS; при неподдерживаемом движке или ошибке запись отклоняется. Обратитесь к администратору базы, если требуется InnoDB; плагин не меняет движок сам.

Максимум 100 форм, 20 вопросов в форме, 12 вариантов вопроса, 20 сообщений; текстовые ограничения совпадают с редактором. Экспорт также ограничен 1 МиБ: если файл больше, выберите меньше форм и сохраните несколько файлов; настройки можно экспортировать отдельно. Файлы импортируются последовательно с новым preview. Нельзя использовать ZIP/PHP или сериализованные PHP-объекты вместо JSON.

## Формат версии 1

Корень: `product: "netchat"`, `schema_version: 1`, `type: "settings" | "forms" | "bundle"`, `timestamp: "YYYY-MM-DDTHH:mm:ssZ"` (UTC). `settings` присутствует только для settings/bundle и содержит полный нормализованный config из netchat_settings без обёртки хранения. `forms` присутствует только для forms/bundle:

```json
{
  "installed": {},
  "primary_form": "",
  "documents": {
    "document_url": "", "policy_url": "", "text_version": "1",
    "document_version": "", "policy_version": ""
  },
  "enabled": 0,
  "retention_confirmed": 0
}
```

`installed` — объект ID → полное определение формы: id, service_code, schema_version, service_label, title, intro, submit_text, success_text, fields; optional enabled, question_steps, notices. При переносе question_steps всегда становится явным, в том числе у старой одношаговой формы. Поля сохраняют key, label, type (short/text/url/radio/multi), required (boolean), step, optional placeholder/helper/options/condition. Условие: key + массив допустимых values из вариантов исходного вопроса. Сообщения сохраняют text, optional condition/any/before_contact/channel_link. Циклы и отсутствующие варианты отклоняются. Никакие поля источника не добавляются в публичные встроенные схемы автоматически.

Публичная установка создаёт только основную нейтральную форму и пример; приём изначально выключен. Обновление сохраняет существующий каталог, настройки и удалённые формы, не восстанавливает их автоматически. В приватном пакете общий runtime тот же; при отсутствии публичного nc_primary_v1 первая приватная схема выбирается основной только при первоначальном создании options. Владелец/сборщик располагает текущую основную форму первой. Существующая основная форма при обновлении сохраняется. Документы и реальные параметры приёма владелец переносит отдельным приватным bundle и проверяет на своём сайте.

Hosted CI для WordPress 5.0/PHP 7.2 и WordPress 7.1.3/PHP 8.3 подготовлен; результат подтверждается только фактическим run. Локальная исходная проверка не является приёмкой SQL rollback, браузера или production-site. JSON не является резервной копией базы данных.
