## 📌 Общая информация

Плагин **NetChat** позволяет добавить на сайт кнопки для быстрой связи через популярные мессенджеры. Для корректной работы необходимо правильно настроить данные для каждого мессенджера.

### Как работает плагин

1. Вы вводите данные (username, номер, email) в настройках плагина
2. Плагин автоматически формирует правильные ссылки
3. На сайте появляется плавающая кнопка с иконками мессенджеров
4. При клике пользователь переходит в выбранный мессенджер

## ⚙ Подробная настройка

### ✈️ Telegram

**Что ввести:** Имя пользователя без символа `@`

**Пример:** `durov`

#### Где взять username:

1. Откройте приложение **Telegram**
2. Перейдите в **Настройки** → **Изменить профиль**
3. Найдите поле **Имя пользователя** (Username)
4. Скопируйте значение **без** символа `@`

#### Правила:

| ✅ Правильно | ❌ Неправильно |
|-------------|---------------|
| `durov` | `@durov` |
| `support_bot` | `t.me/durov` |
| `user123` | `https://t.me/durov` |

#### Важно:

- Username должен быть уникальным
- Можно использовать латинские буквы, цифры и нижние подчёркивания `_`
- Минимальная длина: 5 символов
- Если username не задан в Telegram — ссылка работать **не будет**

#### Дополнительно:

Можно добавить предзаполненное сообщение:
```
https://t.me/username?text=Здравствуйте!
```

### 💬 WhatsApp

**Что ввести:** Номер телефона с кодом страны, только цифры

**Пример:** `79001234567`

#### Требования к номеру:

| ✅ Правильно | ❌ Неправильно |
|-------------|---------------|
| `79001234567` | `+79001234567` |
| `79123456789` | `+7 (912) 345-67-89` |
| `14155551234` | `89123456789` |

#### Правила:

- ✅ **Только цифры**
- ✅ **Без `+`** в начале
- ✅ **Без пробелов**, скобок и тире
- ✅ **С кодом страны** (`7` для России и Казахстана)

#### Коды стран:

| Страна | Код |
|--------|-----|
| 🇷 Россия | `7` |
| 🇰🇿 Казахстан | `7` |
| 🇺🇦 Украина | `380` |
| 🇧🇾 Беларусь | `375` |
| 🇺🇸 США | `1` |

#### Примеры:

| Страна | Номер | Ввести |
|--------|-------|--------|
| Россия | +7 (900) 123-45-67 | `79001234567` |
| Украина | +380 (50) 123-45-67 | `380501234567` |
| США | +1 (415) 555-1234 | `14155551234` |

#### Важно:

- Номер должен быть привязан к аккаунту WhatsApp Business или обычному WhatsApp
- Ссылка `wa.me` работает и на компьютере (откроет WhatsApp Web)

#### Дополнительно:

Можно добавить предзаполненное сообщение:
```
https://wa.me/79001234567?text=Здравствуйте%21
```
Текст должен быть в URL-кодировке (пробел = `%20` или `+`, `!` = `%21`)

### 👥 ВКонтакте

**Что ввести:** Короткое имя профиля (username)

**Пример:** `durov`

#### Где взять username:

1. Откройте вашу страницу **ВКонтакте**
2. Посмотрите на адресную строку: `https://vk.com/username`
3. Скопируйте часть после `vk.com/`

#### Правила:

| ✅ Правильно | ❌ Неправильно |
|-------------|---------------|
| `durov` | `https://vk.com/durov` |
| `username` | `vk.com/id123456` |

#### Если нет короткого имени:

Если у вас нет короткого имени, используйте ID:
1. Откройте вашу страницу VK
2. Посмотрите на адрес: `https://vk.com/id123456`
3. В настройках плагина введите: `id123456`

#### Ссылка на сайте:

`https://vk.me/username` — открывает диалог в VK Мессенджере

### 🔷 MAX

**Пример:** `https://max.ru/u/f9LHodD0cC`

#### Где взять ссылку:

1. Откройте приложение **MAX**
2. Перейдите в **Профиль**

4. Скопируйте ссылку из профиля

#### Правила:

| ✅ Правильно | ❌ Неправильно |
|-------------|---------------|
| `https://max.ru/u/f9LH...` | `f9LHodD0cC` |
| `https://max.ru/u/username` | `max.ru/u/123` |

#### Важно:

- Введите **полную ссылку** начиная с `https://`
- MAX — это обновлённая версия OK (Одноклассники)

### 💜 Viber

**Что ввести:** Номер телефона с `+` в начале

**Пример:** `+79001234567`

#### Требования:

| ✅ Правильно | ❌ Неправильно |
|-------------|---------------|
| `+79001234567` | `79001234567` |
| `+380501234567` | `+7 (900) 123-45-67` |

#### Правила:

- ✅ **С `+`** в начале
- ✅ **С кодом страны**
- ✅ **Без пробелов** и скобок

#### Важно:

⚠️ Ссылка `viber://` работает **только если установлено приложение Viber** на устройстве пользователя.

| Устройство | Поведение |
|------------|-----------|
| 📱 Мобильный с Viber | Откроется чат в приложении |
| 🖥 Компьютер без Viber | **Не откроется** (пустая страница) |
| 🖥 Компьютер с Viber | Откроется приложение Viber |

#### Решение для десктопа:

Если нужно поддержать пользователей без Viber, рассмотрите альтернативу:
- Укажите другой мессенджер (Telegram, WhatsApp)
- Добавьте ссылку на веб-версию: `https://viber.com/`

2. Найдите **Имя пользователя**

## ❌ Частые проблемы

### Telegram: «User not found»

**Проблема:** Username указан неверно или не настроен.

**Решение:**
1. Проверьте, задан ли username в настройках Telegram
2. Убедитесь, что вводите username **без `@`**
3. Проверьте правильность написания (регистр не важен)
4. Минимальная длина username: 5 символов

---

### WhatsApp: не открывается

**Проблема:** Ссылка не работает или открывается пустая страница.

**Возможные причины:**
1. Неправильный формат номера (есть `+`, пробелы или скобки)
2. Номер не привязан к WhatsApp
3. Используется код страны `8` вместо `7` для России

**Решение:**
- Введите номер только цифрами: `79001234567`
- Убедитесь, что номер активирован в WhatsApp
- Для России используйте код `7`, не `8`

---

### VK: не открывается диалог

**Проблема:** Ссылка `vk.me` не работает.

**Возможные причины:**
1. Неправильный username
2. У пользователя закрыты сообщения от незнакомцев

**Решение:**
- Проверьте username: откройте `https://vk.com/username`
- Убедитесь, что у пользователя разрешены сообщения

---

### Viber: не открывается

**Проблема:** Ссылка `viber://` не работает на компьютере.

**Это нормально!** Ссылка `viber://` работает только если установлено приложение Viber.

**Решение:**
1. Предупредите пользователей, что нужен Viber
2. Добавьте альтернативный мессенджер (Telegram, WhatsApp)
3. На десктопе без Viber ссылка не сработает — это ограничение самого Viber

---

### Messenger: показывает ошибку

**Проблема:** Ссылка `m.me` не работает.

**Возможные причины:**
1. Используется личный профиль вместо страницы
2. Не настроено имя пользователя страницы

**Решение:**
1. Убедитесь, что используете **страницу (Page)**, не личный профиль
2. Настройте имя пользователя в **Настройки страницы → Имя пользователя**
3. Проверьте, что страница опубликована и активна

---

### Email: не открывается почта

**Проблема:** При клике ничего не происходит.

**Возможные причины:**
1. На компьютере не настроен почтовый клиент
2. Браузер блокирует `mailto:` ссылки

**Решение:**
- Настройте почтовый клиент по умолчанию
- Или используйте веб-форму обратной связи вместо email

## 💡 Рекомендации

### ✅ Best Practices

1. **Всегда тестируйте ссылки** перед публикацией на сайте
2. **Используйте HTTPS** для всех ссылок (кроме `viber://`, `tel:`, `mailto:`)
3. **Проверяйте на мобильных** — большинство пользователей будут открывать ссылки с телефона
4. **Добавляйте несколько мессенджеров** — у пользователей разные предпочтения
5. **Указывайте актуальные данные** — проверяйте username и номера раз в месяц

### 🔧 URL-кодирование

Для предзаполненных сообщений используйте URL-кодирование:

| Символ | Код |
|--------|-----|
| Пробел | `%20` или `+` |
| `!` | `%21` |
| `?` | `%3F` |
| `&` | `%26` |
| `=` | `%3D` |
| Кириллица | `%D0%...` |

**Пример:**
```
Исходный текст: Здравствуйте!
URL-encoded: %D0%97%D0%B4%D1%80%D0%B0%D0%B2%D1%81%D1%82%D0%B2%D1%83%D0%B9%D1%82%D0%B5%21
```
