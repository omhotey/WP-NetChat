# Загрузка публичных CSS в NetChat 1.2.3

Пять публичных таблиц стилей входят в исходники плагина и по умолчанию встраиваются в HTML без изменения содержимого и порядка WordPress. Отдельный внешний сниппет оптимизации не требуется. Кнопка, анимации, контакты, формы и доставка писем используют прежний код.

## Политика загрузки и возврат

Для обычной загрузки файлов задайте до загрузки WordPress в wp-config.php:

```php
define('NETCHAT_INLINE_STYLES', false);
```

Либо верните boolean false через фильтр `netchat_inline_styles`. Отключающая константа имеет приоритет над фильтром. После смены режима очистите кеш страниц/CDN. Отдельного поля настройки в админке в этом обновлении нет.

При неизвестном handle, изменённом URL/HTML, специальных атрибутах исходной ссылки, другом media, недоступном или неподходящем файле фильтр возвращает исходный HTML. В админке, feed и рабочей области NCF встраивание не применяется. Проверяются локальный путь и размер; относительные URL, import, charset, обратный слеш и HTML-открывающий символ сохраняют внешний режим. Файлы CSS остаются в пакете.

Строгий Content Security Policy, запрещающий inline CSS, требует заранее включить внешний режим. Отказ CSP после выдачи страницы автоматически не обнаруживается и не исправляется этим фильтром. При конфликте стороннего оптимизатора также используйте внешний режим.

## Кеширование

Встраивание убирает до пяти отдельных CSS-запросов, но добавляет около 27 КБ несжатого CSS к каждому HTML-документу. При повторных переходах внешние CSS могут уже находиться в кеше браузера; встроенные байты повторяются. На некешируемую генерацию страницы добавляется чтение локальных CSS; при отдаче готового кешированного HTML фильтр PHP не выполняется. Cookies, различия по пользователям или идентификаторам страниц не вводятся.

Универсальное ускорение и рост оценки Lighthouse не обещаются. Проверяйте несколько холодных и повторных переходов, общий объём HTML/CSS, реальный маршрут пользователя и настройки сжатия/кеша. Внешний режим сохраняет обычное версионирование URL.

## Установка и проверка

Используйте один проверенный ZIP с корнем netchat/. Если прежде действовала внешняя реализация встраивания NetChat CSS, отключите только её часть, сохранив остальные функции сайта. После обновления очистите кеш; анонимно проверьте отсутствие дублированных стилей, кнопку, приветствие, контакты, формы, шаги, modal/drawer на мобильном и компьютере. Данные и почтовый транспорт обновлением CSS не меняются.

При отказе обновления сначала прочитайте фактическую версию. Не повторяйте замену вслепую и не удаляйте плагин: дальнейший способ замены выбирается по доступу и журналам хостинга. Успешная ручная замена не определяет причину прежнего отказа.

## Исходники, сборка и откат

Модуль `includes/style-delivery.php` подключён из `netchat.php`. Штатный `python tools/build-release.py` выбирает зафиксированный версионный сборщик; неизвестная версия, отсутствующий сборщик, модуль или его подключение приводят к ошибке. `python tools/build-release.py --verify-only` проверяет уже существующий результат. PowerShell: `tools/build-release.ps1 -VerifyOnly`; при необходимости передайте `-PythonPath` с установленным Python 3.

Для следующей версии требуется осознанно обновить версию, версионный builder и регистрацию в dispatcher, сохранив модуль и его подключение. Старый builder 1.2.2 сохранён отдельно как исторический, без переключения на него при ошибках текущей версии. [Проверки](../tests/README.md).

Быстрый откат — внешний режим и очистка кеша. Полный — заменить файлы совместимым проверенным пакетом 1.2.2, сохранив актуальную БД и настройки. Не вызывайте uninstall/«Удалить плагин» и не включайте NETCHAT_DELETE_DATA для обновления или отката. [Инструкция](UPGRADE.md).
