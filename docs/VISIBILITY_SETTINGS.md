# Появление кнопки и подсказки

Настройки доступны в главном разделе NetChat. «Показывать подсказку на телефонах» выключено по умолчанию; граница — ширина до 768 px включительно. Кнопка продолжает работать при разрешённой общей мобильной видимости. На широком экране подсказкой управляет её общий выключатель.

Для кнопки и подсказки отдельно задаются время 0–600 целых секунд от открытия страницы и прокрутка 0–100%. Нужно выполнение обоих условий; 0 снимает соответствующее ожидание. Подсказка дополнительно ждёт доступной кнопки. Например: кнопка 5 секунд/25%, подсказка 15 секунд/50%. Короткая страница считается просмотренной на 100%; достигнутый порог сохраняется до перезагрузки.

В 1.2.0 задержка подсказки начиналась после достижения порогов; в 1.2.1 — от открытия страницы. Прежнее число сохраняется. Поздняя загрузка JS не запускает полную задержку заново. Если браузер не предоставляет оба API времени навигации, используется время инициализации.

Закрытие подсказки или открытие меню/формы прекращает её показ до перезагрузки. Внешние кнопки и API не ждут появления плавающей кнопки. Скрытые элементы недоступны для фокуса; изменение ширины не раскрывает запрещённую мобильную подсказку.

Старые настройки без hint_mobile/button_delay получают 0/0 при чтении без записи. Старый REST-клиент сохраняет текущие значения новых полей; старый JSON импортируется с 0/0. Экспорт включает оба поля. Публичные пресеты не заменяют сохранённые формы.
