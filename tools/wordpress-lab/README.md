# WordPress Lab для NetChat

Рабочая папка: `D:\Project\WordPress-Lab`. Требуются Docker Desktop с Linux Engine и PowerShell 7. Исходники NetChat подключены из `D:\Project\WP NetChat`; путь можно изменить через `NETCHAT_PROJECT_PATH` в `.env`.

## Запуск

```powershell
cd 'D:\Project\WordPress-Lab'
.\scripts\start.ps1
```

Команда скачивает закреплённые образы, запускает MariaDB, WordPress и Mailpit, ждёт готовности и устанавливает WordPress только при отсутствии установки. Активный NetChat повторно не активируется. Тестовая страница создаётся один раз; настройки существующего сайта сохраняются.

При отсутствии `.env` команда создаёт его с отдельными случайными паролями. Существующий `.env` сохраняется. Логин, пароль и email администратора находятся в `WORDPRESS_ADMIN_*`; они задают первую установку и не меняют существующего пользователя.

- Сайт: http://localhost:8080/netchat-test/
- Админка: http://localhost:8080/wp-admin/
- Перехваченные письма: http://localhost:8025

Порты доступны только с локального компьютера. Настройки портов задаются в `.env`.

## Проверки и остановка

```powershell
.\scripts\status.ps1
.\scripts\test.ps1
.\scripts\wp.ps1 plugin list
.\scripts\backup.ps1
.\scripts\stop.ps1
```

`test.ps1` проверяет синтаксис PHP, загрузку NetChat и конфигурации, тестовую страницу, HTTP и получение тестового письма Mailpit. Это проверка стенда; функциональные проверки миграции и интерфейса выполняются отдельно.

`stop.ps1` останавливает проект, сохраняя named volumes. Последующий `start.ps1` использует прежние данные. Не добавляйте `-v` к остановке: это удалит хранилища.

## Хранение и резервные копии

Тома: `wordpress-lab_database_data`, `wordpress-lab_wordpress_data`, `wordpress-lab_mailpit_data`. Данные сохраняются при перезагрузке контейнеров; `restart: unless-stopped` возобновляет сервисы после запуска Docker, если они не были остановлены вручную.

`backup.ps1` сохраняет SQL, весь wp-content и wp-config.php, а также SHA256 и размеры файлов. Исходники NetChat исключены из архива: они хранятся в отдельном Git-репозитории. При работающем сайте SQL снимается транзакционно; для согласованной копии файлов не редактируйте контент во время backup. `.env` и backup содержат локальные учётные данные, не публикуйте их. Перехваченные письма Mailpit хранятся в отдельном томе и в backup сайта не входят.

Прежняя копия от 13 августа и старые скрипты остаются в лаборатории. Новый запуск не импортирует архив автоматически и не запускает прежние seed/repair-скрипты.

## Разработка

Один каталог NetChat смонтирован в веб-контейнер и WP-CLI. Меняйте исходники на Windows: контейнер сразу видит их. Mount доступен контейнеру только для чтения; обновление плагина из админки поверх рабочей папки ограничено этим режимом.

Для проверки ZIP-установки и обновления нужна отдельная конфигурация без bind mount NetChat и отдельные тестовые данные. Текущий стенд предназначен для разработки и миграционных проверок.

Локальная MU-функция направляет `wp_mail()` в Mailpit по внутренней Docker-сети; она не входит в NetChat. WordPress debug включён, вывод ошибок посетителю отключён. База и SMTP не публикуют порты на хосте.

Проверенные версии: WordPress 7.0.4, PHP веб-контейнера 8.3.33, PHP CLI 8.3.35, MariaDB 11.8.3, WP-CLI 2.12.0, Mailpit 1.27.0. Образы закреплены также по digest, чтобы последующие изменения тегов не меняли среду. Это не подтверждение поддержки всех минимальных версий плагина.

## Повторная установка конфигурации

Шаблон и установщик хранятся вместе с NetChat в `tools/wordpress-lab`. Установщик переносит конфигурацию в существующую лабораторию и архивирует прежние изменяемые файлы; `.env`, содержимое backups и пользовательские данные сохраняются.
