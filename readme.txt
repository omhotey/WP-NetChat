NetChat добавляет плавающую кнопку связи и формы обращений. Заявки сохраняются в WordPress и доступны администратору сайта.

== Description ==

Версия 1.2.0 опубликована: https://github.com/omhotey/WP-NetChat/releases/tag/v1.2.0

= Каналы и кнопка =

* Telegram, WhatsApp, ВКонтакте, MAX, Viber, Facebook Messenger, электронная почта и телефон.
* Цвет, размер 40–80 px, положение, анимация 0–1000 мс, отдельная видимость на компьютерах и мобильных устройствах.
* Два режима: сразу форма либо меню формы и каналов связи.
* Приветствие с текстом, задержкой и отдельным порогом прокрутки. Пороги кнопки и приветствия — целые 0–100%; 0 означает без ожидания, 100 — конец страницы. Короткая страница считается просмотренной полностью.
* После достижения порога кнопка остаётся доступной до перезагрузки при разрешённой видимости. Время 0–600 секунд отдельно для кнопки и подсказки отсчитывается от открытия страницы. Нужны оба условия: время и собственная прокрутка; подсказка также ждёт кнопку. На телефонах подсказка выключена по умолчанию. Закрытое приветствие и открытая форма не меняются из-за прокрутки.
* Внешние кнопки и API доступны до порога плавающей кнопки. Поддерживаются клавиатура и prefers-reduced-motion.

= Формы и заявки =

Каталог и отдельный редактор позволяют создавать, копировать, включать, удалять формы, настраивать вопросы и проверять предпросмотр. Доступны короткий ответ, текст, URL, один или несколько вариантов, условия и сообщения. Можно выбрать основную форму и настроить привязки страниц.

Новая публичная установка содержит две нейтральные формы: основную и пример. Приём изначально выключен. Существующие формы, основная форма и настройки сохраняются при обновлении; удалённые формы автоматически не восстанавливаются.

Заявка получает постоянный номер и снимок формы. Изменение формы не переписывает старые заявки. Повтор запроса не создаёт дубликат. В разделе заявок доступны просмотр, смена состояния, повтор уведомления и удаление. Закрытие во время отправки не отменяет уже начатый запрос.

= Перенос =

NetChat → Перенос данных экспортирует настройки, выбранные формы или комплект в JSON. Импорт проверяется до записи; копирование используется по умолчанию, замена выбирается явно. Настройки, документы и основная форма переносятся по отдельному выбору. Права администратора, nonce и ревизии проверяются; сохранение выполняется атомарно в InnoDB.

Файл не содержит заявок, авторизации или привязок страниц, но может включать контакты владельца и получателей, документы и тексты форм. Храните его приватно. Максимум — 1 МиБ. Руководство: https://github.com/omhotey/WP-NetChat/blob/main/docs/DATA_TRANSFER.md

= Данные и уведомления =

При включённом приёме сохраняются контакты, ответы, источник, снимок и согласие. Сервисные письма содержат полные сохранённые ответы независимо от переключателя текста обычной контактной формы. Успешный wp_mail означает передачу транспорту, а не доставку.

Сроки хранения и экспорт/стирание WordPress поддерживаются. Поиск для экспорта и стирания выполняется по email; остальные контакты требуют подтверждённого ручного поиска. Удаление не отзывает письма и не удаляет резервные копии хостинга. Обычное удаление плагина сохраняет данные; NETCHAT_DELETE_DATA=true явно включает очистку при uninstall. Переход по контакту открывает внешний сервис.

== Installation ==

1. Скачайте готовый ZIP нужной версии со страницы релизов GitHub; для этой сборки — 1.2.1.
2. Для новой установки или папки netchat/ выберите netchat-wp.zip. Для установленной папки WP-NetChat-main/ выберите netchat-upgrade-WP-NetChat-main.zip. При обновлении сохраните прежнее имя папки и одну активную копию.
3. Сверьте SHA256 с SHA256SUMS.txt и состав архива с соответствующим *.manifest.json.
4. В WordPress откройте Плагины → Добавить новый → Загрузить плагин, установите архив и активируйте NetChat.
5. Откройте NetChat, включите нужные каналы и сохраните контакты.
6. Настройте формы, получателей, срок хранения и реальные документы согласия/политику; явно включите приём. Отправьте синтетическую заявку и проверьте уведомления.

Для новой установки через WP-CLI: `wp plugin install /path/to/netchat-wp.zip --activate`.
Руководство обновления и отката: https://github.com/omhotey/WP-NetChat/blob/main/docs/UPGRADE.md

== Frequently Asked Questions ==

= Как добавить отдельную кнопку формы? =

Используйте блок «Шорткод»: [netchat_button text="Связаться"] или [netchat_form]. Для конкретной формы укажите её service_code в параметре service. Собственная кнопка может использовать data-netchat-open="form". Смотрите руководство разработчика в репозитории.

= Почему плавающая кнопка не видна? =

Проверьте включённые каналы и их ссылки, приём форм, флаги видимости, задержку появления и порог прокрутки. Кнопка появляется при наличии активного канала или включённого приёма формы; после изменения очистите кеш страниц/CDN.

= Что сохраняется при обновлении? =

Настройки, каталог, привязки, основная форма и заявки. Не создавайте вторую установку под другим именем папки. Перед обновлением подготовьте обычную резервную копию средствами владельца сайта.

= JSON заменяет резервную копию базы? =

Нет. Это перенос настроек и определений форм без заявок, истории удаления, сессий и привязок страниц.

= Подтверждает ли CI доставку писем и работу на моём сайте? =

Нет. CI проверяет передачу тестовому почтовому транспорту и изолированные сценарии. Проверьте реальные документы, получателей, доставку, cron, тему, кеш и устройства после установки.
