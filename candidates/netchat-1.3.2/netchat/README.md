# NetChat 1.3.2

Самостоятельная кнопка восьми каналов связи для WordPress 5.0 и новее, PHP 7.2 и новее. Это чистая установка: настройки хранятся в `netchat_settings_v3`, `schema_version=1`, сохранение защищено ревизией и сравнением исходных байтов. Старые настройки и JSON не читаются, автоматической миграции нет. Настройки доступны в пункте NetChat в админке. Все каналы изначально выключены, ссылки пусты.

**Обновление с 1.2.3 и более ранних:** эта версия не переносит настройки, формы и заявки из старого плагина. Установка NetChat Forms сама по себе тоже не переносит эти данные. Не заменяйте старую версию, пока доступ к данным не обеспечен проверенной миграцией. Настройки 1.3.0 и 1.3.1 сохраняются при обновлении.

Поддерживаются Telegram, WhatsApp, Facebook Messenger, MAX, ВКонтакте, Viber, Email и телефон. Язык настроек — русский или английский; размер кнопки 40–80 px, анимация 0–1000 мс, цвет, координаты и отдельная видимость на компьютерах и телефонах. Для кнопки и приветствия независимо задаются время 0–600 секунд и прокрутка 0–100%. Нужны оба условия. Время отсчитывается от открытия страницы, достигнутый порог прокрутки сохраняется до перезагрузки; короткая страница считается просмотренной полностью. Приветствие также ждёт кнопку и по умолчанию скрыто на телефонах. Закрытое приветствие и открытое меню подавляют дальнейший показ приветствия до перезагрузки. Каналы остаются обычными ссылками.

Если единственный доступный канал — форма, основная кнопка сразу открывает её (или выбор форм). При нескольких каналах обычный режим показывает меню, а выбранный режим формы открывает её напрямую. Настроенные контакты остаются доступными Forms через `netchat_get_contacts()`.

## API дополнительных каналов, версия 1

Доступность: `NETCHAT_CHANNELS_API_VERSION === 1`. Чтение каналов: `netchat_get_channels()`. Фильтр `netchat_channels` получает включённые каналы с корректными ссылками в настроенном порядке. Он возвращает массив с дополнительными записями. Если возвращён не массив, используются исходные каналы; некорректные записи пропускаются. Callback должен быть чистым и не изменять хранилище NetChat.

Ключ записи: `^[a-z][a-z0-9_-]{0,31}$`. Обязательны текстовая подпись `label`, строгое `enabled => true` и ровно одно поле: `url` либо `action`. Для встроенного протокола передают `channel` с ключом штатного канала; без него принимаются абсолютные HTTP(S)-ссылки без учётных данных. Необязательная статическая SVG-иконка проходит ограниченный sanitizer: запрещены скрипты, обработчики событий, style, href, внешние ресурсы и анимация.

```php
add_filter('netchat_channels', function ($channels) {
    $channels['forms'] = array('label'=>'Форма', 'enabled'=>true,
        'action'=>'netchat-forms-open',
        'icon'=>'<svg viewBox="0 0 24 24"><path d="M5 4h14v16H5z" fill="none" stroke="currentColor" stroke-width="2"/></svg>');
    return $channels;
});
```

Дополнение публикует этот канал только при доступной форме. Действие отображается нативной кнопкой `type=button`. NetChat закрывает меню и один раз за активацию указателем или нативной клавиатурой отправляет на `document` событие `CustomEvent('netchat:action', {detail:{action:'netchat-forms-open'}})`. Дополнение слушает document и самостоятельно управляет окном, фокусом, проверками, отправкой и хранением данных. Формат action: `^[a-z][a-z0-9_-]{0,63}$`. Одновременные `url` и `action` отклоняются.

Дополнительный канал может включить виджет без штатных ссылок. NetChat не зависит от Forms: без дополнения его канала нет. Forms остаётся самостоятельным плагином.

## Установка и границы

Установочный пакет имеет один корень `netchat/`. В новую сборку не входят движок форм, редактор, заявки, почта, обработка персональных данных, импорт, cron и миграции. Одновременно активна только одна копия NetChat. Установку, отключение старых копий и решения о старых данных выполняет администратор сайта отдельно. Эта сборка не является инструментом миграции; при удалении настройки автоматически не очищаются.

Изолированные тесты используют подмены WordPress и синтетическую модель DOM. Они не доказывают интеграцию с WordPress, отображение в браузере, работу реального устройства, установку на сайт или доставку почты. Фактический интерпретатор тестов — PHP 8.3; минимум 7.2 сохранён в коде, но отдельно на 7.2 не запускался.


## Оформленная админка — уточнение R2

Восстановлены карточки каналов с исходными иконками и цветами, переключатели Material Design 3, раскладка1140 px /420 px+1fr, группы положения, внешнего вида, приветствия с HTML-панелью B/I/BR/A, видимости, языка и кнопки сохранения/сброса. Все четыре координаты и порядок восьми каналов сохраняются. Порядок редактируется кнопками вверх/вниз по понятным названиям, без ввода технических ключей.

Предпросмотр компьютера/телефона показывает текущие цвета, размер, положение, каналы, приветствие и условия времени/прокрутки. Это дополнение к прежнему оформлению; в каноническом шаблоне1.2.2 такого предпросмотра не было. Внутри рамки координаты масштабируются, условия задаются ползунками, ссылки не открываются. Приветствие строится безопасными HTML-узлами B/I/BR/A; неподдерживаемые элементы и опасные протоколы не исполняются.

Сохранение использует прежний защищённый механизм netchat_settings_v3 через авторизованный AJAX-адаптер. При ошибке, конфликте или изменениях во время отправки черновик остаётся на странице. «Сбросить» восстанавливает только настройки виджета в черновике; для применения нажмите «Сохранить настройки». Язык интерфейса после успешного сохранения применяется при обновлении страницы.

Оформление и поведение проверены автономным Edge на PHP-render с подменами WordPress,320/390/1440 px. Это проверка HTML/CSS/JS, а не работа реальной WordPress-админки, её сети и установки. Публичный widget runtime, API и хранилище R1 не изменены.
