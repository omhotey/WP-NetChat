Бесплатная кнопка связи на сайт с 8 мессенджерами. Плавающие кнопки для WordPress: Telegram, WhatsApp, VK, MAX, Viber, Messenger, Email, Телефон.

== Description ==

**NetChat** — это бесплатный WordPress плагин для добавления плавающей кнопки связи с поддержкой 8 популярных мессенджеров и способов связи. Кнопка на сайт устанавливается за 2 минуты без написания кода.

### ⚡ Возможности

* **8 мессенджеров:** Telegram, WhatsApp, ВКонтакте, MAX, Viber, Facebook Messenger, Email, Телефон
* **Кастомизация:** размер кнопки, цвет, позиция, скорость анимации
* **Лёгкий:** без зависимостей, без внешних библиотек, минимальный вес
* **Приватность:** никакого трекинга, без внешних серверов, GDPR compliant
* **Доступность:** ARIA-метки, клавиатурная навигация, поддержка `prefers-reduced-motion`
* **Мультиязычность:** переводы на русский и английский из коробки
* **Адаптивность:** отдельные настройки для десктопа и мобильных устройств

### 🔧 Как это работает

1. Установите и активируйте плагин
2. Перейдите в **Настройки → NetChat**
3. Включите нужные мессенджеры и введите данные
4. Нажмите «Сохранить настройки»
5. Готово! Кнопка появится на вашем сайте

### 📱 Поддерживаемые мессенджеры

| Мессенджер | Что ввести | Пример |
|------------|-----------|--------|
| Telegram | Имя пользователя (без @) | `durov` |
| WhatsApp | Номер с кодом страны | `79001234567` |
| ВКонтакте | Имя пользователя | `username` |
| MAX | Ссылка на профиль | `https://max.ru/u/...` |
| Viber | Номер с + | `+79001234567` |
| Messenger | Имя пользователя FB | `username` |
| Email | Ваш email | `info@example.com` |
| Телефон | Номер в любом формате | `+7 (900) 123-45-67` |

### 🎨 Кастомизация

* **Позиция:** справа внизу или слева внизу
* **Размер:** от 40 до 80 пикселей
* **Цвет:** любой HEX цвет
* **Анимация:** от 0 до 1000 миллисекунд
* **Подсказка:** текст всплывающей подсказки
* **Видимость:** десктоп и/или мобильные устройства

### 🔒 Приватность

NetChat не собирает, не хранит и не передаёт никакие персональные данные. Плагин полностью соответствует GDPR.

### ♿ Доступность

* ARIA-метки для всех элементов
* Клавиатурная навигация (Tab, Enter, Escape)
* Поддержка `prefers-reduced-motion`
* Скрыт при печати (`@media print`)

### 📋 Требования

* WordPress 5.0 или выше
* PHP 7.0 или выше

== Installation ==

### Вариант 1: Через админку WordPress (ZIP)

1. Скачайте архив с [GitHub](https://github.com/omhotey/WP-NetChat/releases)
2. Перейдите в **Плагины → Добавить новый**
3. Нажмите **Загрузить плагин** → выберите ZIP-файл
4. Нажмите **Установить** → **Активировать**
5. Перейдите в **Настройки → NetChat** для настройки

### Вариант 2: Через FTP

1. Распакуйте архив
2. Загрузите папку `netchat` в `wp-content/plugins/`
3. Активируйте через **Плагины** в админке WordPress

### Вариант 3: Через WP-CLI

`wp plugin install --activate https://github.com/omhotey/WP-NetChat/releases/latest/download/netchat-wp.zip`

== Frequently Asked Questions ==

= Это действительно бесплатно? =

Да! NetChat полностью бесплатен. Без рекламы, без PRO-версий, без скрытых платежей. Open Source под лицензией GPLv2+.

= Плагин собирает данные? =

Нет. NetChat не собирает, не хранит и не передаёт никакие персональные данные. Полностью GDPR compliant.

= Какие мессенджеры поддерживаются? =

8 каналов связи: Telegram, WhatsApp, ВКонтакте, MAX, Viber, Facebook Messenger, Email и Телефон.

= Можно настроить внешний вид? =

Да! Размер кнопки, цвет, позиция, скорость анимации — всё настраивается через панель настроек.

= Как добавить кнопку на сайт? =

Загрузите ZIP через Плагины → Добавить → Загрузить, или распакуйте в wp-content/plugins/netchat/ и активируйте. Кнопка на сайт появится автоматически.

= Плагин работает с кэшированием? =

Да. Плагин корректно работает с большинством плагинов кэширования.

= Где взять имя пользователя Telegram? =

Откройте Telegram → Настройки → Изменить профиль → Имя пользователя. Введите без символа `@`.

= Как получить ссылку WhatsApp? =

Введите номер телефона в международном формате без `+`, пробелов и скобок. Например: `79001234567`.

= Viber не открывается на компьютере =

Ссылка `viber://` работает только если установлено приложение Viber. На десктопе ссылка не сработает — это ограничение самого Viber.

= Messenger показывает ошибку =

Ссылка `m.me` работает только для страниц (Pages) Facebook, не для личных профилей. Настройте имя пользователя в настройках страницы.
